# 학습 범위

학습 대상은 물리 시스템의 운동, 측정, 구동 및 제어를 이해하는 데 필요한 과학과 공학 분야입니다. 핵심 분야와 세부 주제는 [README.md](../README.md#3-학습-분야)를 참고합니다.

- 핵심 분야를 우선하고, 선수 지식은 필요한 범위에서 설명합니다.
- 새로운 분야를 추가할 때 기존 주제와의 연관성을 확인합니다.
- 관련성이 낮은 이론은 깊게 확장하지 않습니다.
- 모든 개념을 특정 응용 사례에 연결하거나 한 학문 전체를 처음부터 끝까지 다루려 하지 않습니다.
- 명시적인 요청이 있으면 범위를 확장할 수 있습니다.

깊이는 학습 목적에 맞춰 조절합니다.

- 미적분학: 물리량의 변화, 시스템 모델링, 근사에 필요한 개념
- 전자기학: 회로, 자기장, 전자기 유도, 전동기 원리를 이해하는 데 필요한 내용
- 역학: 힘, 운동, 회전, 강체 운동, 유체의 기본 원리
- 컴퓨터과학: 수치 계산, 임베디드 시스템, 실시간 처리, 장치 통신에 관련된 내용
