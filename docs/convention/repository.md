# 파일 및 디렉터리 규칙

기존 파일과 관련 문서를 확인하고, 명확한 필요가 있을 때만 구조를 바꿉니다. 요청하지 않은 내용을 삭제하거나 관련 없는 파일을 수정하지 않습니다.

## 이름

- 디렉터리와 Markdown 파일: `kebab-case`
- Python 파일: `snake_case`
- 설정 파일: 기존 프로젝트 관례

## 위치

| 경로 | 용도와 기준 |
| --- | --- |
| `docs/` | 웹사이트에 게시할 학습 Markdown과 작업별 규칙을 둡니다. 게시 대상은 `mkdocs.yml`의 목차와 제외 설정에서 관리합니다. |
| `fundamentals/` | 학문 분야별 개념, 정의, 수학적 근거를 정리합니다. 설명과 유도를 우선하고 관련 실험은 상대 경로로 연결할 수 있습니다. |
| `experiments/` | 명확한 목적을 가진 작은 독립 실험을 둡니다. 매개변수와 실행 방법을 기록하고 실험 전용 코드를 유지합니다. |
| `simulations/` | 문서에서 실행할 수 있는 독립적인 시뮬레이터의 Python 원본을 둡니다. 생성된 웹 파일은 `docs/simulations/`에 저장하며 커밋하지 않습니다. |
| `modules/` | 실제로 재사용하는 알고리즘과 유틸리티를 둡니다. 특정 실험에 종속되지 않게 하고 공개 인터페이스와 테스트를 마련합니다. |
| `projects/` | 독립적인 구현과 통합 실습을 둡니다. 필요한 구조와 README를 프로젝트별로 만들고 의존성과 실행 환경을 해당 프로젝트에서 관리합니다. |
| `resources/` | 참고 문헌과 학습 자료를 둡니다. 공식 자료와 신뢰할 수 있는 출처를 우선하고 출처를 기록하며 저작권 자료를 무단 복제하지 않습니다. |

중복 학습 문서를 불필요하게 만들거나 프로젝트 사이를 불필요하게 결합하지 않습니다.

## 학습 단원의 개요

- 여러 문서로 나뉜 학습 단원은 해당 폴더의 `index.md`를 개요 페이지로 두고 사이트 탐색 메뉴의 첫 항목에 연결합니다.
- 개요에는 단원의 목적, 필요한 선수 지식, 권장 학습 순서와 하위 문서 링크를 간결하게 적습니다. 개별 문서의 유도·예제는 개요에 반복하지 않습니다.
- 상위 목차는 단원 개요로 연결합니다. 하위 문서 목록은 각 단원의 개요에서 관리해 같은 목록을 여러 곳에서 수정하지 않도록 합니다.
