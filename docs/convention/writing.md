# 학습 문서 작성 규칙

학습 문서는 개념을 이해하고 다른 문제에 적용할 수 있도록 작성합니다. 정답뿐 아니라 이유를 설명하고, 중요한 선수 지식과 이미 다룬 개념을 연결합니다. 기존 설명과 중복되지 않도록 관련 문서를 먼저 확인합니다.

## 언어와 표기

- 학습 문서는 한국어로 작성합니다. 기술 용어는 처음 나올 때 영어 원문을 병기할 수 있습니다.
- 수학적 표현에는 LaTeX 문법을 사용합니다.
- 변수와 상수의 의미를 정의하고 물리량에는 단위를 표기합니다.
- 간결하고 정확한 한국어를 사용하며 불필요한 영어 문장과 번역투를 피합니다.
- 실제로 확인한 참고 자료만 출처로 적습니다.

## 구성

필요에 따라 개요, 학습 목적, 선수 지식, 개념 및 정의, 수학적 원리, 공식 유도, 직관적 해석, 예제, 응용, 한계 및 주의사항, 요약, 참고 자료를 사용합니다. 모든 문서에 같은 구조를 강제하거나 내용이 없는 절을 만들지 않습니다.

## 개념 설명

- 개념이 필요한 이유와 해결하려는 문제를 먼저 설명합니다.
- 새로운 용어는 사용하기 전에 정의합니다.
- 직관적인 설명과 엄밀한 정의를 구분합니다.
- 추상적인 개념에는 가능한 한 구체적인 예시를 사용합니다.
- 필요한 선수 지식을 간단히 설명하고 관련 개념과 연결합니다.
- 개념과 관계없는 주제로 불필요하게 확장하지 않습니다.

## 수학적 유도

- 공식만 제시하지 않고 유도 과정을 설명하며 중요한 중간 계산을 보존합니다.
- 사용한 정리와 미분·적분 규칙, 변수 치환 관계를 밝힙니다.
- 수식의 각 항이 의미하는 바를 설명합니다.
- 극한, 연속성, 미분 가능성 등 성립 조건을 구분합니다.
- 근사식과 정확한 관계식을 구분하고 차원과 단위가 일치하는지 확인합니다.

## 물리적 해석

- 수학적 결과의 물리적 의미, 모델의 가정과 적용 범위를 설명합니다.
- 이상적인 조건과 실제 환경의 차이를 밝히고 물리적으로 성립하지 않는 해석을 피합니다.
- 필요한 경우 에너지, 힘, 운동, 전압, 전류 등의 관계를 연결합니다.
- 측정 오차와 외부 환경의 영향을 고려합니다.

## 예제와 연습문제

- 새 개념이나 정리를 설명할 때는 **문제 예시와 풀이를 적어도 하나** 포함합니다. 적용 조건 확인, 계산, 결과 해석이 이어지도록 구성합니다.
- 한 단계의 공식 대입만으로 끝나는 문제나 핵심을 가리는 복잡한 문제를 피하고, 개념을 구별할 수 있는 적당한 난도로 만듭니다.
- 공학적 사용 사례를 우선합니다. 관련성이 자연스러우면 드론의 고도·추력·비행 경로·센서 신호·제어 입력을 예로 들고, 가상 모델과 실제 측정값을 구분합니다.
- 핵심 개념을 이해하는 데 필요한 예제를 우선합니다.
- 계산 과정을 단계별로 보이고 결과값의 의미를 해석합니다.
- 계산 문제와 개념 확인 문제를 구분합니다.
- 과도하게 복잡한 예제로 핵심을 흐리지 않습니다.
- 필요에 따라 수치 계산이나 시뮬레이션으로 확장합니다.
