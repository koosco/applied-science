# 코드 작성 규칙

코드는 학습 목적에 맞게 핵심 알고리즘과 사용한 수식을 이해하기 쉬운 형태로 드러냅니다. 정확성과 가독성을 우선하고 기존 코드 스타일을 존중합니다.

## 공통

- 변수명과 함수명은 영어를 사용합니다. 주석은 한국어를 기본으로 하되 알고리즘과 수식의 의미가 필요할 때 작성합니다.
- 코드 자체로 분명한 내용을 주석으로 반복하지 않습니다.
- 실험 전용 코드와 재사용 모듈을 구분하고, 실제 재사용 필요성이 있을 때 분리합니다.
- 불필요한 프레임워크, 외부 의존성, 과도한 객체지향 설계와 추상화를 피합니다.

## Python

Python 3를 수치 계산과 시뮬레이션의 기본 언어로 사용합니다.

- PEP 8과 `snake_case`를 따릅니다.
- 필요할 때 타입 힌트를 작성하고 파일 경로에는 `pathlib` 사용을 권장합니다.
- NumPy, SciPy, Matplotlib 등은 필요한 경우에 사용합니다.
- 계산 로직과 출력 로직을 분리하고 전역 상태를 최소화합니다.

하드웨어 인터페이스, 실시간 처리, 성능 요구에 따라 C, C++ 또는 다른 언어를 사용할 수 있습니다. 언어는 학습 목적과 기술적 요구에 맞게 선택합니다.

## 재사용 모듈 검증

- 핵심 기능의 단위 테스트를 작성합니다.
- 입력의 경계 조건과 필요한 예외 상황을 확인합니다.
- 재현 가능한 테스트를 우선합니다.
