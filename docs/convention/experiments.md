# 실험 및 시뮬레이션 규칙

실험은 개념을 검증하거나 수학적 모델의 동작을 관찰하기 위해 작성합니다. 실행하지 않은 코드의 결과를 임의로 기록하지 않으며, 시뮬레이션 결과를 실제 측정값처럼 표현하지 않습니다.

## 기록할 내용

필요에 따라 실험 목적, 이론적 배경, 수학적 모델, 가정과 초기 조건, 입력값과 매개변수, 구현·실행 방법, 예상 결과, 실행 결과, 결과 분석, 한계와 개선 사항을 기록합니다.

## 수치 계산과 검증

- 사용한 수치 알고리즘을 밝히고 수치 근사와 해석적 해를 구분합니다.
- 시간 간격과 샘플링 주기의 영향, 계산 오차와 수치적 안정성을 검토합니다.
- 가능한 경우 알려진 해, 수학적 성질 또는 이론적 예측과 결과를 비교합니다.
- 오차나 예상 밖의 결과는 원인을 분석하고 임의로 수정하지 않습니다.

## 물리 시스템 모델링

- 상태변수와 입력변수, 시스템의 지배방정식을 설명합니다.
- 초기 조건과 경계 조건을 명시합니다.
- 근사와 단순화 가정, 모델의 적용 범위와 한계를 설명합니다.
- 측정 오차나 실제 환경의 영향을 고려합니다.

## 재현성

- 실행 환경과 의존성을 기록하고 입력 매개변수를 수정하기 쉽게 구성합니다.
- 난수가 필요한 경우 시드를 관리합니다.
- 가능한 한 계산과 시각화 로직을 분리합니다.
- 생성 파일은 필요한 경우에만 저장합니다.

## 그래프와 상호작용

- 입력값을 바꿨을 때 그래프의 좌표와 계산 결과가 실제로 갱신되는지 서로 다른 값으로 확인합니다.
- 입력값에 따른 변화를 비교할 때는 축 범위와 단위를 고정하거나, 축 범위가 바뀌면 그 사실을 명확하게 표시합니다.
- 좌표를 나타내는 그래프에는 축 눈금과 단위를 표시하고, 그래프 위에 마우스를 올리면 해당 지점의 x, y 값을 확인할 수 있게 합니다.
- 좌표 툴팁은 화면 표시 기준 글자 크기 16px 이상, 좌우 여백 12px 이상, 상하 여백 8px 이상으로 만듭니다. SVG를 축소해 표시할 때는 실제 화면에서 읽을 수 있는 크기인지 확인합니다.
- 시뮬레이터에는 항상 초기화 버튼을 두고, 모든 입력값·그래프·계산 결과가 첫 렌더링 상태로 돌아가는지 확인합니다.
- 웹에 게시한 시뮬레이터를 수정할 때는 문서의 임베드 주소도 갱신해 이전 HTML 캐시가 표시되지 않게 합니다.
