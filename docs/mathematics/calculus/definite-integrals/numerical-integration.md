# 수치적분: 측정값으로 누적량 구하기

> 정적분 7/7 · 권장 학습 시간: 30~45분  
> 선수 지식: [리만 합](riemann-sums.md), [미적분학의 기본정리](fundamental-theorem.md)

## 함수식이 없고 측정값만 있다면?

실제 센서는 연속적인 함수 $v(t)$를 알려 주기보다 일정한 시점에서 측정한 값 $\{(t_i,v_i)\}$을 제공합니다. 이때는 원시함수로 적분할 수 없으므로 **수치적분(numerical integration)**으로 정적분을 근사합니다.

실제 측정값이 없다면 수학적 함수에서 가상의 샘플을 생성하여 먼저 방법을 검증할 수 있습니다. 아래 계산은 모두 **가상 데이터**입니다.

## 직사각형과 사다리꼴 근사

시간이 $t_0<t_1<\cdots<t_n$인 샘플을 측정했다고 가정합니다. 구간별 시간 폭은 $\Delta t_i=t_{i+1}-t_i$입니다.

왼쪽 시점의 측정값을 사용한 좌측 합은

\[
L=\sum_{i=0}^{n-1} v_i\Delta t_i
\]

이고, 오른쪽 시점의 측정값을 사용한 우측 합은

\[
R=\sum_{i=0}^{n-1} v_{i+1}\Delta t_i
\]

입니다.

**사다리꼴법(Trapezoidal Rule)**은 두 측정값을 직선으로 연결해 그 구간의 넓이를 근사합니다.

\[
\boxed{
T=\sum_{i=0}^{n-1}
\frac{v_i+v_{i+1}}2\,(t_{i+1}-t_i)
}
\]

이 식은 측정 시점의 간격이 서로 달라도 적용할 수 있습니다. 샘플 사이 값이 직선적으로 변하면 구간별 계산이 정확하지만, 곡선이면 오차가 생길 수 있습니다.

## 문제 예시: 속도 샘플 세 개로 변위 근사하기

가상의 물체의 실제 속도 함수가 $v(t)=t^2$ (m/s, $t$는 초 단위의 수치)라고 가정하고, 1초 간격으로만 측정했습니다.

| 시간 $t$ (s) | 속도 $v$ (m/s) |
| ---: | ---: |
| 0 | 0 |
| 1 | 1 |
| 2 | 4 |

좌측 합, 우측 합, 사다리꼴법의 근삿값과 정확한 적분값을 비교합니다.

**풀이.** 각 간격은 1초입니다.

\[
L=0\times1+1\times1=1\,\mathrm m,
\]

\[
R=1\times1+4\times1=5\,\mathrm m.
\]

사다리꼴법은 각 구간의 평균 속도를 사용합니다.

\[
T=\frac{0+1}{2}\times1+
\frac{1+4}{2}\times1
=0.5+2.5=3\,\mathrm m.
\]

정확한 정적분값은

\[
\int_0^2 t^2\,dt
=\left[\frac{t^3}{3}\right]_0^2
=\frac83\,\mathrm m\approx2.667\,\mathrm m.
\]

따라서 사다리꼴법의 **절대오차**는 $|3-8/3|=1/3\,\mathrm m$, **상대오차**는 $(1/3)/(8/3)=12.5\%$입니다. 이 예제에서는 사다리꼴법이 실제 값을 다소 크게 근사합니다.

0.5초 간격으로 더 자주 샘플링하면 사다리꼴법의 근삿값은 $2.75$ m가 되어 오차가 $1/12$ m로 감소합니다. 다만 실제 측정에는 센서 오차가 있으므로 **샘플을 촘촘히 측정한다고 모든 오차가 사라지는 것은 아닙니다.**

## Python으로 직접 계산하기

아래 코드는 별도의 라이브러리 없이 실행할 수 있습니다. 입력값은 앞선 예제의 **가상 샘플**입니다.

~~~python
samples = [(0.0, 0.0), (1.0, 1.0), (2.0, 4.0)]

if not all(samples[i][0] < samples[i + 1][0]
           for i in range(len(samples) - 1)):
    raise ValueError("시간은 엄격히 증가해야 합니다.")

estimate = sum(
    (samples[i][1] + samples[i + 1][1]) / 2
    * (samples[i + 1][0] - samples[i][0])
    for i in range(len(samples) - 1)
)
exact = 8 / 3

print(f"사다리꼴 근사: {estimate:.4f} m")
print(f"정확한 변위: {exact:.4f} m")
print(f"절대오차: {abs(estimate - exact):.4f} m")
~~~

예상 출력은 **3.0000 m, 2.6667 m, 0.3333 m**입니다. 샘플을 0.5초 간격으로 바꾸고 오차가 어떻게 달라지는지 비교해 보세요.

## 확인 문제

시간 간격이 일정하지 않은 다음 속도 샘플을 사다리꼴법으로 적분해 변위를 근사해 보세요.

| 시간 (s) | 속도 (m/s) |
| ---: | ---: |
| 0 | 0 |
| 0.5 | 1 |
| 2 | 1 |

## 확인 문제 풀이

첫 구간은 폭 0.5초, 둘째 구간은 폭 1.5초입니다.

\[
T=\frac{0+1}{2}\times0.5+
\frac{1+1}{2}\times1.5
=0.25+1.5
=1.75\,\mathrm m.
\]

시간 간격이 일정하다고 가정해 하나의 $\Delta t$를 모든 구간에 곱하면 틀립니다.

## 이번 장에서 기억할 것

- 실제 센서값은 연속함수가 아니라 **이산 샘플**이므로 수치적분을 사용합니다.
- 사다리꼴법은 인접한 두 측정값의 평균에 **해당 구간의 시간 폭**을 곱합니다.
- 샘플링 간격, 보간 방식, 측정 오차에 따라 결과가 달라집니다.
- 계산된 누적량이 변위인지 이동 거리인지, 단위가 무엇인지 항상 확인합니다.
