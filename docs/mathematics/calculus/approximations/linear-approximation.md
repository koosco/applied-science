# 선형 근사와 미분(differentials)

> 근사 1/4 · 선수 지식: [미분계수와 접선](../differentiation/derivatives-and-tangents.md)

## 왜 접선으로 예측할까?

미분 가능한 함수 $f$의 점 $x=a$에서 접선의 기울기는 $f'(a)$입니다. 이 점 근처에서 함수는 접선과 비슷하게 움직이므로

\[
\boxed{L(x)=f(a)+f'(a)(x-a)}
\]

를 **선형 근사(linear approximation)**라고 합니다. $f(a)$는 출발값, $f'(a)(x-a)$는 입력의 작은 변화에 대한 예상 출력 변화입니다. 등호 $f(x)=L(x)$가 아니라 **$f(x)\approx L(x)$**에 주의합니다.

미분을 작은 변화의 근사로 쓰면 $dy=f'(a)\,dx$, $\Delta y=f(a+\Delta x)-f(a)\approx dy$입니다. 미분 가능성은 $\Delta x\to0$에서 오차가 $|\Delta x|$에 비해 충분히 작아진다는 것을 의미합니다.

## 그래프로 이해하기

![함수 y=x²와 x=2에서의 접선 y=4+4(x−2)가 x=2에서 접하는 그래프](../../../assets/figures/calculus/approximations/linear-vs-quadratic.svg)

*접점에서는 정확하고, 떨어진 곳에서는 곡률 때문에 오차가 커집니다.*

## 문제 예시: 제곱 함수의 짧은 구간 예측

$f(x)=x^2$이고 $a=2$일 때 $x=2.1$의 값과 선형 근사를 비교하세요.

**풀이.** $f(2)=4$, $f'(x)=2x$이므로 $f'(2)=4$입니다. 따라서

\[
L(2.1)=4+4(0.1)=4.4.
\]

정확한 값은 $f(2.1)=2.1^2=4.41$이고 절대오차는 $0.01$입니다. $x=2.2$에서는 선형 근사가 4.8, 정확한 값은 4.84이므로 오차가 0.04로 증가합니다. **기준점에서 멀어지면 더 큰 오차가 생길 수 있습니다.**

## 확인 문제

$f(x)=\sqrt{x}$를 $a=4$에서 선형 근사해 $\sqrt{4.2}$를 예측하세요.

## 확인 문제 풀이

$f(4)=2$, $f'(x)=1/(2\sqrt x)$이므로 $f'(4)=1/4$입니다.

\[
L(4.2)=2+\frac14(0.2)=2.05.
\]

실제 $\sqrt{4.2}\approx2.04939$로 오차는 약 $0.00061$입니다. 입력 0.2는 여기서 $x$의 수치 변화이며, 실제 물리 모델에 적용하려면 $x$와 $f$의 단위도 정의해야 합니다.
