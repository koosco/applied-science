# 미적분 학습 목차

센서값으로 상태를 추정하고 물리량의 변화를 계산하는 데 필요한 내용을 기초 네 단원과 확장 네 단원, 모두 여덟 단원으로 나눴습니다. 각 단원의 개요에서 학습 순서와 세부 문서를 찾을 수 있습니다.

| 단원 | 핵심 질문 |
| --- | --- |
| [함수](functions/index.md) | 입력과 출력을 연결하고, 역함수의 존재와 극한·연속을 어떻게 판단하는가? |
| [미분법](differentiation/index.md) | 순간 변화율을 계산해 운동·민감도·극값을 어떻게 해석하는가? |
| [부정적분](indefinite-integrals/index.md) | 변화율에서 원시함수를 어떻게 찾고 적분 기법을 선택하는가? |
| [정적분](definite-integrals/index.md) | 변화율을 구간에 걸쳐 누적해 전체 변화량을 어떻게 계산하는가? |
| [근사·급수](approximations/index.md) | 미분을 이용해 복잡한 함수를 어느 정도 정확도로 단순화할 수 있는가? |
| [매개변수 곡선](parametric-curves/index.md) | 2차원 궤적의 변화율과 실제 이동 길이를 어떻게 계산하는가? |
| [다변수 미적분](multivariable/index.md) | 편미분·그래디언트·다중 적분은 무엇을 설명하는가? |
| [벡터 미적분](vector-calculus/index.md) | 공간의 장과 경로·경계를 따른 누적량을 어떻게 해석하는가? |

함수의 극한을 이해한 뒤 미분법을 읽고, 미분 공식을 거꾸로 사용하며 부정적분으로 이어갈 수 있습니다. 이후 정적분에서 변화율의 누적과 미적분학의 기본정리를 학습합니다. 필요한 단원부터 시작해도 각 개요에서 선수 지식과 관련 문서를 확인할 수 있습니다.


## 그래프로 이해하기

![함수, 미분법, 부정적분, 정적분 네 단원의 개념 연결 흐름도](../../assets/figures/calculus/calculus-learning-map.svg)

*입출력 관계를 익힌 뒤 변화율을 계산하고, 원시함수와 정적분으로 누적량을 구하는 학습 순서입니다.*

## 다음 단원

기초 미적분을 마쳤다면 먼저 **[벡터와 좌표계](../coordinate-systems/index.md)**에서 위치·방향과 기준축을 복습하고, [선형 근사·급수](approximations/index.md) → [매개변수 곡선](parametric-curves/index.md) → [다변수 미적분](multivariable/index.md) → [벡터 미적분](vector-calculus/index.md) 순으로 진행합니다. 기초 네 단원 흐름도는 기존 핵심 개념의 연결을 설명하는 그림이며, 확장 네 단원은 위의 문서 링크에서 이어서 읽습니다.

**현재 문서는 학습 자료의 준비 상태**를 나타냅니다. 문제를 풀고 개념을 설명할 수 있는지는 각 단원의 완료 기준으로 별도 확인해야 합니다. 미분방정식, 선형대수학, 복잡한 곡면 적분 정리는 별도 학습 분야에서 이어갑니다.
