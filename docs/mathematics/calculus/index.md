# 미적분 학습 목차

센서값으로 상태를 추정하고 물리량의 변화를 계산하는 데 필요한 내용을 **함수**와 **미분법**으로 나눴습니다. 각 문서에는 성립 조건, 유도 또는 증명, 응용 예제를 담았습니다. 그래프를 조작할 수 있는 주제에는 시뮬레이터를 연결했습니다.

## 함수

| 순서 | 문서 | 다루는 질문 |
| --- | --- | --- |
| 1 | [합성함수](functions/composition.md) | 측정과 단위 변환을 연달아 적용하면 어떤 함수가 되는가? |
| 2 | [단사·전사와 역함수](functions/inverse-functions.md) | 출력에서 입력을 유일하게 되찾으려면 어떤 조건이 필요한가? |
| 3 | [함수의 극한과 연속](functions/limits-and-continuity.md) | 값이 가까워질 때의 결과와 목표값의 존재를 어떻게 판단하는가? |
| 응용 | [주기 함수와 신호 시스템](functions/periodic-signals.md) | 반복되는 진동에서 주파수·진폭·위상을 어떻게 읽는가? |

## 미분법

| 순서 | 문서 | 다루는 질문 |
| --- | --- | --- |
| 1 | [미분계수와 도함수](differentiation/derivatives-and-tangents.md) | 순간속도와 접선·법선은 어떻게 구하는가? |
| 2 | [롤의 정리](differentiation/theorems/rolle.md) | 같은 출력값 사이에 변화율이 0인 순간이 있는가? |

| 4 | [로피탈의 정리](differentiation/theorems/lhopital.md) | $0/0$형과 $\infty/\infty$형 극한을 언제 도함수로 계산할 수 있는가? |
| 5 | [역함수의 미분법](differentiation/inverse-function-derivatives.md) | 출력 목표가 조금 변할 때 입력은 얼마나 바뀌는가? |
| 6 | [음함수의 미분법](differentiation/implicit-differentiation.md) | 두 변수가 하나의 관계식에 묶여 있을 때 기울기는 무엇인가? |

표의 순서대로 읽으면 **극한·연속 → 도함수 → 평균값 정리 → 도함수를 이용한 응용**으로 이어집니다. 필요한 주제만 골라 읽어도 각 문서에서 가정과 변수를 다시 확인할 수 있습니다.
