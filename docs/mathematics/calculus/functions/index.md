# 함수

측정값을 물리량으로 바꾸거나, 입력에 따라 결과가 어떻게 달라지는지 설명하려면 먼저 함수를 다뤄야 합니다. 이 단원에서는 **함수의 연결 → 입력을 되찾는 조건 → 극한과 연속 → 연속함수의 두 정리 → 반복되는 신호** 순서로 읽을 수 있습니다. 필요한 개념만 골라 읽어도 됩니다.

| 순서 | 문서 | 다루는 질문 |
| --- | --- | --- |
| 1 | [합성함수](composition.md) | 센서 보정과 단위 변환을 연달아 적용하면 어떤 함수가 되는가? |
| 2 | [단사·전사와 역함수](inverse-functions.md) | 출력에서 입력을 유일하게 되찾으려면 어떤 조건이 필요한가? |
| 3 | [함수의 극한과 연속](limits-and-continuity.md) | 입력이 한 값에 가까워질 때의 결과와 연속성을 어떻게 판단하는가? |
| 4 | [중간값 정리](intermediate-value-theorem.md) | 연속함수가 목표값에 도달하는 입력이 존재하는가? |
| 5 | [최대·최소 정리](extreme-value-theorem.md) | 닫힌 구간에서 가장 작거나 큰 값에 실제로 도달하는가? |
| 응용 | [주기 함수와 신호 시스템](periodic-signals.md) | 반복되는 진동에서 주파수·진폭·위상을 어떻게 읽는가? |

합성함수와 극한은 [미분법](../differentiation/index.md)의 바탕이 됩니다. 역함수는 센서 출력에서 입력을 추정하거나 [역함수의 도함수](../differentiation/inverse-function-derivatives.md)를 이해할 때 다시 사용합니다. 주기 함수 문서는 신호의 반복 특성을 다루는 응용 사례입니다.
