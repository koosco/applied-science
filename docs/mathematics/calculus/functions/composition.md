# 합성함수

센서에서 얻은 전압을 물리량으로 바꾸고, 다시 다른 단위로 환산하는 일은 함수의 연속 적용입니다. 먼저 적용하는 함수가 $f$, 다음이 $g$라면 **합성함수**는

\[
(g\circ f)(x)=g(f(x))
\]

입니다. $x$는 $f$의 정의역에 있어야 하고, $f(x)$는 $g$의 정의역에 있어야 합니다. 적용 순서를 바꾸면 보통 결과가 달라집니다.

예를 들어 센서 전압의 수치를 $v$ (V), 섭씨온도의 수치를 $T$ (°C), 화씨온도의 수치를 $F$ (°F)라 합시다. 이 센서의 가상 보정식을 $T=f(v)=100v-50$으로 두고 표시 단위를 $F=g(T)=\tfrac95T+32$로 바꾼다면

\[
F=(g\circ f)(v)=\frac95(100v-50)+32=180v-58.
\]

$v=0.75$ (전압 $0.75\,\mathrm V$)에서는 $T=25\,{}^\circ\mathrm C$, $F=77\,{}^\circ\mathrm F$입니다. 계수 100의 단위는 °C/V이며, 실제 센서의 보정식은 장치에 따라 달라집니다.

합성함수의 변화율은 [연쇄법칙](../differentiation/basic-rules.md#chain-rule)으로 계산합니다. $f$와 $g$가 해당 지점에서 미분 가능하면 $(g\circ f)'(x)=g'(f(x))f'(x)$입니다. 이 예에서는 $180\,{}^\circ\mathrm F/\mathrm V$가 됩니다. 연쇄법칙은 [역함수의 미분법](../differentiation/inverse-function-derivatives.md)에서도 사용합니다.

## 문제 예시: 드론 가속도 센서의 세 단계 환산

중력 성분을 제거한 가상 수직 가속도 센서가 전압을 출력합니다. $v$는 전압을 V 단위로 나타낸 수치이며 $1.5\le v\le2.0$입니다. 먼저 무차원 보정값 $q(v)=(v-1.5)/0.5$를 만들고, 적용 범위가 $0\le q\le1$인 가속도 모델 $a(q)=(q+q^2)\,\mathrm{m/s^2}$에 넣습니다. 처음 수직 속도가 0이고 가속도가 $2\,\mathrm s$ 동안 일정하다면 변위는 $d(a)=\tfrac12a(2\,\mathrm s)^2$입니다. 전압에서 변위까지의 합성함수를 구하고, $v=1.75$ (전압 $1.75\,\mathrm V$)의 변위와 허용 전압에서 가능한 변위 범위를 구해 보세요. 전압이 $2.1\,\mathrm V$일 때에도 같은 식을 적용할 수 있는지 판단해 보세요.

**풀이.** 적용 순서는 전압 → 보정값 → 가속도 → 변위입니다. $q\in[0,1]$이므로 $a$의 입력 조건을 만족하며,

\[
(d\circ a\circ q)(v)
=2\left[\frac{v-1.5}{0.5}+\left(\frac{v-1.5}{0.5}\right)^2\right]\,\mathrm m.
\]

$v=1.75$이면 $q=0.5$, $a=0.75\,\mathrm{m/s^2}$이어서 변위는 $1.5\,\mathrm m$입니다. $0\le q\le1$에서 $q+q^2$는 증가하므로 변위 범위는 $[0,4]$ m입니다. $2.1\,\mathrm V$는 보정식에 대입할 수 있어도 **센서의 허용 전압 범위 밖**이므로 이 모델로 변위를 해석할 수 없습니다. 이는 일정 가속도를 가정한 계산이며 실제 위치 추정에는 초기 속도·자세·센서 오차가 영향을 줍니다.
