# 합성함수

센서에서 얻은 전압을 물리량으로 바꾸고, 다시 다른 단위로 환산하는 일은 함수의 연속 적용입니다. 먼저 적용하는 함수가 $f$, 다음이 $g$라면 **합성함수**는

\[
(g\circ f)(x)=g(f(x))
\]

입니다. $x$는 $f$의 정의역에 있어야 하고, $f(x)$는 $g$의 정의역에 있어야 합니다. 적용 순서를 바꾸면 보통 결과가 달라집니다.

예를 들어 센서 전압의 수치를 $v$ (V), 섭씨온도의 수치를 $T$ (°C), 화씨온도의 수치를 $F$ (°F)라 합시다. 이 센서의 가상 보정식을 $T=f(v)=100v-50$으로 두고 표시 단위를 $F=g(T)=\tfrac95T+32$로 바꾼다면

\[
F=(g\circ f)(v)=\frac95(100v-50)+32=180v-58.
\]

$v=0.75$ (전압 $0.75\,\mathrm V$)에서는 $T=25\,{}^\circ\mathrm C$, $F=77\,{}^\circ\mathrm F$입니다. 계수 100의 단위는 °C/V이며, 실제 센서의 보정식은 장치에 따라 달라집니다.

합성함수의 변화율은 연쇄법칙으로 계산합니다. $f$와 $g$가 해당 지점에서 미분 가능하면 $(g\circ f)'(x)=g'(f(x))f'(x)$입니다. 이 예에서는 $180\,{}^\circ\mathrm F/\mathrm V$가 됩니다. 연쇄법칙은 [역함수의 미분법](../differentiation/inverse-function-derivatives.md)에서도 사용합니다.
