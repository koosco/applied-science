# 다변수 미적분: 함수, 미분, 적분

한 변수만 변하는 모델에서 벗어나면 온도·추력·에너지 비용이 **위치, 시간, 제어 입력 등 여러 변수**에 함께 의존할 수 있습니다. 다변수 미적분은 한 번에 하나의 변수만 바꾸는 **편미분**, 여러 방향의 변화인 **그래디언트**, 좌표 변환의 **야코비안**, 면적·부피에 걸친 **중적분**을 다룹니다.

## 학습 깊이

**필수:** 편미분·그래디언트·연쇄법칙·접평면·야코비안 및 이중적분의 의미. **권장:** 극좌표 면적 요소와 삼중적분의 단위 해석. Hessian과 라그랑주 승수는 기본 예제까지만 다룹니다. 엄밀한 다중적분의 존재성 증명과 고차원 좌표계의 일반 정리는 나중에 확장합니다.
