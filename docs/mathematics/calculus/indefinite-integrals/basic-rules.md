# 부정적분의 기본 공식

[도함수 공식](../differentiation/basic-rules.md)을 거꾸로 읽으면 기본적인 원시함수를 구할 수 있습니다. 식을 적분한 뒤 미분해 검산하는 습관은 적분상수와 계수의 누락을 막는 가장 직접적인 방법입니다.

## 선형성과 거듭제곱

$F'=f$, $G'=g$이고 $a,b$가 상수라면 $(aF+bG)'=af+bg$입니다. 그러므로

\[
\int[af(x)+bg(x)]\,dx=a\int f(x)\,dx+b\int g(x)\,dx
\]

로 계산하고 **마지막에 적분상수 하나**를 붙입니다. 각 항에 붙은 임의 상수는 합쳐서 하나의 $C$로 쓸 수 있기 때문입니다.

$n\ne-1$이면 $\frac{d}{dx}[x^{n+1}/(n+1)]=x^n$이므로

\[
\int x^n\,dx=\frac{x^{n+1}}{n+1}+C.
\]

실수 지수에는 보통 $x>0$을 가정하고, 음의 정수 지수에는 $x=0$을 제외합니다. $n=-1$을 위 식에 넣으면 분모가 0이 되므로 별도로 $\int dx/x=\ln|x|+C$입니다. 이 식은 $x=0$을 가로지르지 않는 구간에서 사용합니다. $x>0$이면 $(\ln x)'=1/x$, $x<0$이면 $(\ln(-x))'=1/x$이어서 절댓값이 나타납니다.

## 지수·로그와 자주 쓰는 형태

| 적분할 함수 | 원시함수 | 조건 |
| --- | --- | --- |
| $1$ | $x+C$ | 전체 실수 |
| $e^x$ | $e^x+C$ | 전체 실수 |
| $e^{kx}$ | $e^{kx}/k+C$ | 상수 $k\ne0$ |
| $a^x$ | $a^x/\ln a+C$ | $a>0$, $a\ne1$ |
| $1/x$ | $\ln|x|+C$ | $x\ne0$인 각 구간 |
| $\sin x$ | $-\cos x+C$ | $x$는 라디안 |
| $\cos x$ | $\sin x+C$ | $x$는 라디안 |

$e^{kx}$를 미분하면 $k e^{kx}$가 되므로 $1/k$가 필요합니다. 일반적인 $e^{g(x)}$에서는 $g'(x)$가 함께 있는지 확인해야 하며, 그때는 [치환적분](substitution.md)을 사용합니다. 로그 자체 $\int\ln x\,dx$는 이 표에서 바로 구할 수 없고 [부분적분](integration-by-parts.md)으로 계산합니다.

## 문제 예시: 가상 각속도 계획의 원시함수

드론의 한 축 각속도를 $\omega(t)=(0.4+0.3t+0.2e^{-t})\,\mathrm{rad/s}$로 계획했습니다. $t$는 초 단위 시간의 수치이고, 계수는 식 전체가 rad/s가 되도록 정한 가상값입니다. $\theta'(t)=\omega(t)$, $\theta(0)=0.1\,\mathrm{rad}$일 때 $\theta(t)$와 $\theta(2)$를 구해 보세요.

**풀이.** 선형성, 거듭제곱 공식, $e^{-t}$의 원시함수 $-e^{-t}$를 차례로 적용합니다.

\[
\theta(t)=0.4t+0.15t^2-0.2e^{-t}+C.
\]

$t=0$을 넣으면 $-0.2+C=0.1$이므로 $C=0.3$입니다. 따라서 $\theta(2)=1.7-0.2e^{-2}\approx1.673\,\mathrm{rad}$입니다. 이 결과를 미분하면 $\omega(t)$가 나오고, 시작 각도도 만족합니다. 실제 자세 추정은 자이로스코프의 바이어스와 다른 센서의 보정까지 고려해야 합니다.
