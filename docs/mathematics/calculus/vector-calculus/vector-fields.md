# 벡터장: 위치마다 주어진 방향

> 벡터 미적분 1/5 · 선수 지식: 2차원 벡터와 다변수 함수

## 한 위치가 아니라 공간 전체의 벡터

벡터장 $\mathbf F(x,y)=(P(x,y),Q(x,y))$은 각 점 $(x,y)$에 크기와 방향을 가진 벡터를 대응시킵니다. 예를 들어 바람의 **속도장**은 위치마다 바람이 불어가는 방향과 속력을 표현합니다.

벡터장은 특정 물체가 실제로 따르는 궤적 자체가 아닙니다. 물체의 운동 경로를 구하려면 시간에 따른 위치의 미분방정식 등 추가 조건이 필요합니다.

## 그래프로 이해하기

*오른쪽 점에서 위쪽, 위쪽 점에서 왼쪽을 향합니다. 화살표의 크기는 원점에서 멀수록 커집니다.*

## 문제 예시: 회전 형태의 벡터장

무차원 좌표에 대한 벡터장 $\mathbf F(x,y)=(-y,x)$가 있을 때 $(1,0)$, $(0,1)$, $(2,0)$의 벡터를 비교하세요.

**풀이.** 성분에 좌표를 대입하면

\[
\mathbf F(1,0)=(0,1),\quad
\mathbf F(0,1)=(-1,0),\quad
\mathbf F(2,0)=(0,2).
\]

첫 두 점의 벡터 크기는 1, 마지막 점의 크기는 2입니다. 이 벡터장은 원점 주변의 **반시계 방향을 가리키지만**, 특정 물체가 실제로 원운동한다는 사실까지 보장하지는 않습니다.

## 확인 문제

$\mathbf G(x,y)=(x,y)$에서 $(3,4)$의 벡터와 크기를 구하세요.

## 확인 문제 풀이

$\mathbf G(3,4)=(3,4)$이고 크기는 5입니다. 이 벡터장은 각 점에서 바깥쪽으로 향합니다.
