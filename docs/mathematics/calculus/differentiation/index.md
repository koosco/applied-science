# 미분법

미분은 입력을 조금 바꿨을 때 출력이 얼마나 달라지는지 계산합니다. 드론의 위치에서 속도·가속도를 구하거나, 센서와 추력 모델의 민감도를 해석할 때 같은 원리를 사용합니다. [극한과 연속](../functions/limits-and-continuity.md)을 먼저 읽으면 도함수의 정의와 정리의 조건을 이해하기 쉽습니다.

| 순서 | 문서 | 다루는 질문 |
| --- | --- | --- |
| 1 | [미분계수와 도함수](derivatives-and-tangents.md) | 순간속도와 접선·법선은 어떻게 구하는가? |
| 2 | [기본 미분법](basic-rules.md) | 여러 함수가 결합된 운동·센서 모델의 변화율을 어떻게 계산하는가? |
| 3 | [비행 궤적의 고계도함수](trajectory-derivatives.md) | 위치·속도·가속도·저크는 어떻게 이어지는가? |
| 4 | [도함수로 극값 찾기](extrema.md) | 허용 범위에서 가장 큰 값이나 작은 값을 어떻게 찾는가? |
| 5 | [롤의 정리](theorems/rolle.md) | 같은 출력값 사이에 변화율이 0인 순간이 있는가? |
| 6 | [코시의 평균값 정리](theorems/cauchy-mean-value.md) | 구간의 변화량 비율과 한 순간의 변화율 비율은 어떻게 연결되는가? |
| 7 | [로피탈의 정리](theorems/lhopital.md) | $0/0$형과 $\infty/\infty$형 극한을 언제 도함수로 계산할 수 있는가? |
| 8 | [역함수의 미분법](inverse-function-derivatives.md) | 출력 목표가 변할 때 필요한 입력 변화는 얼마인가? |
| 9 | [음함수의 미분법](implicit-differentiation.md) | 두 변수가 한 관계식에 묶여 있을 때 기울기는 무엇인가? |

먼저 1~4번으로 **계산과 운동 해석**을 익힌 뒤, 5~7번에서 정리의 성립 조건과 증명을 살펴볼 수 있습니다. 8~9번은 입력과 출력의 관계를 역으로 보거나 명시적으로 풀지 않고 변화율을 구하는 방법입니다. 각 문서에는 적용 조건과 문제 풀이가 있습니다.
