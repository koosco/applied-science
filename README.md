# Applied Science

수학, 물리학, 전자공학 및 제어 시스템의 원리를 학습하고,
수학적 분석과 프로그래밍 실험을 통해 이해하는 개인 지식 저장소입니다.

## 1. 소개

Applied Science는 물리 시스템의 동작 원리를 이해하고,
이를 수학적으로 모델링하며 실제 계산과 실험으로 검증하기 위한
학습 저장소입니다.

단순한 공식 암기나 기술 사용법 습득보다는
현상을 설명하는 기본 원리를 이해하고,
서로 다른 학문 사이의 관계를 파악하는 것을 목표로 합니다.

학습한 이론은 개념 문서, 수학적 유도, 코드 실험,
시뮬레이션 및 재사용 가능한 모듈 형태로 정리합니다.

## 2. 학습 목표

- 수학적 개념을 물리 현상과 연결하여 이해합니다.
- 힘, 운동, 에너지 및 회전 운동의 원리를 학습합니다.
- 전기와 자기 현상을 이해하고 회로 및 구동 시스템에 적용합니다.
- 센서의 측정 원리와 데이터 처리 방법을 학습합니다.
- 동적 시스템을 수학적으로 모델링하고 해석합니다.
- 피드백 제어와 상태 추정의 원리를 이해합니다.
- 프로그래밍과 시뮬레이션을 통해 이론을 검증합니다.
- 학습한 알고리즘과 구현을 재사용 가능한 형태로 정리합니다.

## 3. 학습 분야

### 3.1 수학 (Mathematics)

물리 현상을 수학적으로 표현하고 시스템의 동작을 분석하기 위한 기초를 학습합니다.

- 미적분학
  - 극한과 연속
  - 미분과 적분
  - 다변수 미적분
  - 편미분과 그래디언트
  - 테일러 전개 및 선형 근사
- 선형대수학
  - 벡터와 행렬
  - 좌표계와 좌표 변환
  - 고유값과 고유벡터
- 미분방정식
  - 일계 및 이계 미분방정식
  - 연립 미분방정식
  - 동적 시스템의 수학적 표현
- 수치해석
  - 수치 미분과 적분
  - 수치적 미분방정식 풀이
  - 계산 오차와 수치적 안정성

### 3.2 역학 (Mechanics)

물체의 운동과 힘 사이의 관계를 이해합니다.

- 운동학 (Kinematics)
  - 위치, 속도, 가속도
  - 직선 운동과 곡선 운동
  - 각도, 각속도, 각가속도
- 동역학 (Dynamics)
  - 뉴턴의 운동 법칙
  - 힘과 운동량
  - 일과 에너지
  - 토크와 회전 운동
- 강체역학 (Rigid Body Mechanics)
  - 관성모멘트
  - 질량중심
  - 강체의 병진 및 회전 운동
  - 3차원 자세 표현
- 유체 및 공기역학
  - 유체의 기본 성질
  - 압력과 유동
  - 양력과 항력
  - 추력과 운동의 관계

### 3.3 전자기학 (Electromagnetism)

전기 및 자기 현상의 기본 원리와 전자기적 에너지 변환을 학습합니다.

- 전하와 전기장
- 전위와 전압
- 전류와 전류밀도
- 자기장과 자기력
- 전자기 유도
- 인덕턴스
- 전자기력과 회전 운동의 관계

### 3.4 회로 및 전력 시스템 (Circuits and Power Systems)

전기 에너지의 전달, 변환 및 제어 원리를 학습합니다.

- 회로이론
  - 옴의 법칙
  - 키르히호프 법칙
  - 저항, 커패시터, 인덕터
  - RC, RL, RLC 회로
  - 과도응답 및 정상상태
- 전력 시스템
  - 전력과 에너지
  - 전력 손실과 효율
  - 배터리의 전기적 특성
  - 전압 및 전류 변환
- 전기 구동
  - 전동기의 동작 원리
  - BLDC 모터
  - PWM
  - 모터 드라이버 및 ESC
  - 속도와 토크 제어

### 3.5 신호 및 제어 (Signals and Control)

시간에 따라 변화하는 신호와 동적 시스템을 분석하고 제어하는 방법을 학습합니다.

- 신호 및 시스템
  - 연속시간 및 이산시간 신호
  - 샘플링
  - 주파수와 푸리에 해석
  - 필터링
- 시스템 모델링
  - 전달함수
  - 상태공간 모델
  - 선형화
  - 시스템 응답
- 제어공학
  - 개루프 및 폐루프 제어
  - 피드백 제어
  - PID 제어
  - 안정성
  - 응답 특성 및 제어기 설계

### 3.6 센서 및 상태 추정 (Sensors and Estimation)

물리량을 측정하고 불완전한 측정값으로부터 시스템의 상태를 추정하는 방법을 학습합니다.

- 센서 및 계측
  - 가속도계
  - 자이로스코프
  - 자기계
  - 기압 센서
  - 위치 및 거리 측정
  - GNSS
- 데이터 처리
  - 측정 오차와 노이즈
  - 센서 보정
  - 디지털 필터링
  - 샘플링과 시간 동기화
- 상태 추정
  - 확률 및 통계 기초
  - 센서 융합
  - 칼만 필터
  - 위치, 속도 및 자세 추정

### 3.7 임베디드 시스템 (Embedded Systems)

하드웨어와 소프트웨어가 상호작용하는 시스템의 구조를 학습합니다.

- 마이크로컨트롤러
- 메모리와 주변장치
- 인터럽트와 타이머
- 실시간 처리
- 하드웨어 인터페이스
  - GPIO
  - UART
  - I2C
  - SPI
  - CAN
- 장치 간 통신
- 데이터 수집 및 처리
- 하드웨어와 소프트웨어 통합

학습 범위는 실제 필요에 따라 확장하거나 세분화합니다.
관련성이 낮은 주제는 단순한 지식 확장을 목적으로 추가하지 않습니다.

## 5. 학습 방법

학습은 다음 과정을 기본으로 진행합니다.

1. **개념 이해**
   - 학습하려는 개념의 정의와 필요성을 이해합니다.

2. **원리 분석**
   - 개념이 성립하는 이유와 기본 법칙을 학습합니다.

3. **수학적 유도**
   - 관련 수식을 직접 유도하고 변수 사이의 관계를 분석합니다.

4. **물리적 해석**
   - 수학적 결과가 실제 현상에서 무엇을 의미하는지 이해합니다.

5. **실험 및 검증**
   - 필요한 경우 프로그래밍과 시뮬레이션으로 검증합니다.

6. **결과 정리**
   - 가정, 계산 과정, 실험 결과 및 한계를 기록합니다.

모든 개념에 구현이 필요한 것은 아닙니다.
개념을 정확하게 이해하는 것을 우선합니다.

## 9. 문서 사이트와 시뮬레이터

[포물선 운동 문서](docs/mechanics/projectile-motion.md)는 수식 설명 아래에서 Python 시뮬레이터를 실행할 수 있습니다. 문서의 원본은 Markdown이고, 시뮬레이터의 원본은 [`simulations/`](simulations/)의 Python 파일입니다. 사이트를 만들 때 marimo가 시뮬레이터를 브라우저용 HTML로 내보내고 MkDocs가 문서와 함께 제공합니다.

### 로컬 실행

Python 3.12를 기준으로 저장소 루트에서 실행합니다.

```sh
python3.12 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python -m unittest discover -s tests
python -m marimo export html-wasm simulations/projectile_motion.py -o docs/simulations/projectile --mode run --no-show-code
python -m mkdocs serve
```

브라우저에서 `http://127.0.0.1:8000/`을 열면 문서와 시뮬레이터를 함께 볼 수 있습니다. 시뮬레이터 Python 파일을 수정한 뒤에는 위 `marimo export` 명령을 다시 실행합니다. 생성된 `docs/simulations/`, `site/`, `.venv/`는 Git에서 제외합니다.

시뮬레이터만 편집하거나 실행하려면 `python -m marimo edit simulations/projectile_motion.py` 또는 `python -m marimo run simulations/projectile_motion.py`를 사용합니다. 브라우저용 HTML은 인터넷을 통해 Pyodide와 필요한 패키지를 불러옵니다.

### GitHub Pages

`main` 브랜치에 푸시하면 [배포 워크플로](.github/workflows/docs.yml)가 테스트, 시뮬레이터 내보내기, 사이트 생성을 거쳐 `gh-pages` 브랜치에 게시합니다. 저장소의 **Settings → Pages**에서 게시 소스를 `gh-pages` 브랜치로 설정하면 `https://koosco.github.io/applied-science/`에서 볼 수 있습니다.
